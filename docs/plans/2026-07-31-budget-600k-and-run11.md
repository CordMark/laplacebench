# 正準出力トークン上限を600kへ引き上げ、上限が縛らない条件で持ち越し効果を測る

## Direction Brief

1. **Purpose** — Run 9(350k)は persistent 側の上限枯渇による終盤全没収が勝敗を
   支配し、「持ち越しは対局の質に効くのか」という本来の問いに答えられなかった。
   上限を実証対象から外し(ユーザー指示)、同じペアを上限が縛らない条件で再測する。

2. **Concept owner** — 350k 引き上げ時(docs/plans/2026-07-29-token-budget-350k.md)
   と同一: 正準値は `packages/cli/src/runner.ts` の
   `CANONICAL_OUTPUT_TOKEN_BUDGET` が所有し、cli.ts はそれを default resolution と
   help へ導出、契約説明は `docs/match-conduct-laplace-8x8-v1.md` が所有する。

3. **Lifecycle and scope** — 2026-07-31 以後に既定値で開始する LLM 含有対局へ
   適用。過去 run・明示 `--output-token-budget` は不変。350k 時代の run との比較は
   封筒条件が異なる観察比較としてのみ扱う(run.json に値が記録済みで機械的に
   区別可能)。実験 Run 11 を事前登録・実測し FINDINGS / community 台帳へ。
   harness 側 compaction 条件・memo ペアの再走・キャップ sweep は今回作らない。

4. **Value hierarchy** — 本来の問い(持ち越しの質への効果)を測れること >
   ユーザー指示の文字通りの値(500k) > サブスク消費・実験時間。**逸脱の明記**:
   指示は「500kくらい」、採用は 600k(+2割)。根拠: Run 9 実測で persistent
   Sol@medium の 46 手完走所要は ~470-510k(game-000: ply38 で 350k + 終盤
   ~40k/手 ×3-4 手)。500k では同規模でも再枯渇の確率が高く、指示の意図
   (上限を実証対象から外す)を達成できない。600k は実測所要 + 約2割の余裕で、
   50 手級まで上限が主役にならない。人間は安価に 500k へ差し戻せる。

5. **Adopted direction** —
   - `CANONICAL_OUTPUT_TOKEN_BUDGET = 600_000`。help 文言・match-conduct 文書の
     現行値と根拠を同期(350k の履歴は残す)。
   - **事前登録実験 Run 11**: `laplacebench play --team-a
     codex-cli:gpt-5.6-sol@medium --team-b codex-cli-reset:gpt-5.6-sol@medium
     --games 4 --swap --seed 42 --run-id
     harnesslab-sol56m-persistent-vs-reset-600k-20260731`。
     Run 9 と同一プロトコル(4局・seed 42/1042/2042/3042・seat 交互・max-plies
     100・turn timeout 1,200,000ms・並列・clean-room 既定)、封筒のみ 600k
     (新既定)。停止規則 = 固定4局・途中打ち切り・再抽選なし。全滅時のみ別
     run-id で1度再実行(別報告)。問い: Run 9 の reset 3-1 は上限枯渇の産物
     だったか。上限が縛らないとき持ち越しは正に効くか。**Run 9 との比較は
     封筒条件が異なる別 run の観察比較**とラベルし、上限開示値の変化が支出
     ペースへ与える影響は分解しない。55 手超・horizon で再枯渇した場合は
     「その長さでは持ち越しコストが現実的な予算を超える」事実の観測として報告。
   - 結果は verify 通過後に community/runs/keisuke70--… へコピーしてコミット、
     FINDINGS Run 11(n=4 規律)。

6. **What disappears / is not protected** — 350k という既定値(過去 run の記録は
   不変)。Run 9/10 と Run 11 の同条件比較。500k という文字通りの値(逸脱を明記の
   上で 600k)。harness 側 compaction・memo 500k/600k 再走・キャップ sweep は
   今回作らない。「効率が強さになる」競技テーゼの実証は本スライスの目的ではない
   (今回は測定条件の整備)。
