# Published community matchup records

Generated by `.github/workflows/community-publish.yml` from `community/runs`
on `main` after every merge. **Do not edit by hand** — the next publish
overwrites it.

This branch has no source history: it holds exactly the two derived files, so
`main` stays the raw ledger and one workflow owns the aggregate.

- `standings.json` — public data contract, schema `laplace-bench-standings-v2`
- `MATCHUPS.md` — the same data, human-readable

Consumed via the raw URL:

```
https://raw.githubusercontent.com/keisuke70/laplacebench/standings/standings.json
```
